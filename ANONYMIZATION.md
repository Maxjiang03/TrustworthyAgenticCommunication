# Review snapshot transformations

The distribution excludes Git metadata/history, author metadata, personal workspace paths, editing records, caches, virtual environments, build outputs and unused runs. Third-party dependency attribution is retained under its original license.

The synthetic end-user identifier is `user-owner`, and the application authorization namespace is `https://aasc.example.test/rar/tool-authority`. These neutral values are applied consistently to source, tests and regenerated corpora. The identity-registry digest is recomputed with the existing registry hash function. The opaque access-token example and its independently calculated known-answer digest are updated consistently. Grant sets, tools, attack definitions, policy rules, sampling parameters and scoring predicates are unchanged.

Archive execution no longer requires Git solely to populate a provenance field. Source hashes and the release file manifest identify the code instead. Two history/document-audit modules and two historical audit methods are excluded because the review snapshot does not distribute the original Git/decision history. The retained functional assertions are not weakened.

Retained JSON observations are serialized compactly. Personal path fragments and Git identity metadata are removed. Released-file digests refer to this distribution; source hashes inside archived study records describe the recorded study snapshots. The file manifest also records uncompressed digests for gzip data files.

Cryptographic fault-observation captures are regenerated with the neutral identifiers so that their tokens and signatures remain valid. They are identified as anonymized validation captures. The original paper's scalar outcomes, model traces and timing observations are retained; recomputed summaries and the anonymized security reruns verify the reported outcomes before release.

No API credential or model weight is part of the distribution. Test seeds, fake bearer-token examples and synthetic secret markers are intentionally public fixture material, not service credentials.
